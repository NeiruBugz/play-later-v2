### Silent no-ops and traps

- Tailwind v4 does not apply variants to classes declared in `@layer utilities`: 15 tokens produce no CSS — `button.tsx:14,16,20` `hover:shadow-paper`; `card.tsx:13` `hover:shadow-paper-md`; `dialog.tsx:71`, `sheet.tsx:93` `sm:space-x-md` (desktop dialog footer buttons have no gap); `command.tsx:28` ×4, `:85` ×2 arbitrary-variant spacing; `command.tsx:99`, `select.tsx:138` `-mx-xs`; `whats-new-modal.tsx:74` `sm:gap-sm`; `dashboard-jump-back-in-hero.tsx:80` `md:heading-md`.

## Web research findings

### shadcn/ui theming (2025–2026)

- Stock variables: `--radius`, background/foreground, card, popover, primary/secondary/accent/muted (+foreground), destructive, border/input/ring, chart-1..5, 8 sidebar vars; oklch values; mapped via `@theme inline`. https://ui.shadcn.com/docs/theming
- Radius: one base `--radius: 0.625rem`, derived `sm` 0.6× … `4xl` 2.6×. https://ui.shadcn.com/docs/theming
- Base colors now Neutral, Stone, Zinc, Mauve, Olive, Mist, Taupe. https://ui.shadcn.com/docs/theming
- Official customization path: edit token values; add new tokens via `@theme inline`; or presets. https://ui.shadcn.com/docs/theming
- Timeline: Tailwind v4 (Feb 2025), unified `radix-ui` (Jun 2025), CLI 3.0 (Aug 2025), `shadcn create` with styles Vega/Nova/Maia/Lyra/Mira (Dec 2025), Luma (Mar 2026), Sera + `preset`/`apply` (Apr 2026), **Base UI default** (Jul 2026). https://ui.shadcn.com/docs/changelog , https://ui.shadcn.com/docs/changelog/2025-12-shadcn-create , https://ui.shadcn.com/docs/changelog/2026-04-preset-commands
- `shadcn apply <preset> --only theme|font` changes theme/font without reinstalling components. https://ui.shadcn.com/docs/cli
- new-york appears legacy (not in current CLI docs); a non-official mirror says CLI v4 removed `--style`. Unconfirmed. → the tech spec must pick: re-pull new-york primitives vs adopt a current style (Vega closest) and Radix vs Base UI.
- Tailwind v4: `--spacing` single base unit; `--*: initial` wipes namespaces; display font via `--font-display` in `@theme`. https://tailwindcss.com/docs/theme

### Avoiding the generic look

- shadcn as "a coloring template… a starting point". https://x.com/shadcn/status/1849934533111709875
- Levers: warm tinted neutrals, deliberate radius, real display face, one accent used sparingly, one signature shadow, one non-stock token (grain/easing/border). Pitfalls: default theme, components before tokens, forking instead of tokens, second accent, agents drifting back to stock. https://freedesignmd.com/blog/shadcn-looks-generic
- Derive tokens from a written brief (warmth, contrast, density, geometry, formality, motion, type); avoid same radius everywhere, mixed warm/cool grays, Inter as display, logo-only differentiation. https://uxskill.laithjunaidy.com/blog/shadcn-ui-looks-generic.html

### Comparable apps

- Letterboxd: 2:3 poster grid as primary navigation, hover lift + gradient caption, layered dark surfaces, color carries meaning, "diary" framing for logging. https://blakecrosley.com/guides/design/letterboxd ; dark-only base (unofficial) https://styles.refero.design/style/d98dea0b-00a4-4c15-b4a9-d196e2c3e4b4
- Backloggd: minimal chrome, IGDB covers carry color, 4–5-cover list mosaics. https://backloggd.com/ , https://tildes.net/~games/s3m/backloggd_letterboxd_for_video_games
- User critique: art-forward minimal UI + low-friction logging wins; text boxes and sliders feel "like homework". https://dynamicdonut.bearblog.dev/tracking-sites-2
- **Name collision:** "SavePoint" by Two Average Gamers (https://savepoint.twoaveragegamers.com/), "Track your games like you track movies", "Decision Engine" suggesting games by mood/time/platform. Original on Replit 2024; rebuilt on Next.js April 2026 (https://savepoint.twoaveragegamers.com/about); listed on AlternativeTo 2026-03-06. Also "SavePoint: Game Tracker" on the App Store by a different developer (https://apps.apple.com/app/id6780217908).

### Reset sequencing

- Tokens before components; phased migration; codemods module by module with visual regression; consolidation should be visually neutral, intentional changes as a separate step. https://designsystemproblems.pages.dev/token-management/design-token-migration-guide , https://designsystemproblems.pages.dev/token-management/design-token-refactoring
- Lint guard against off-system classes after consolidation (eslint-plugin-better-tailwindcss `no-restricted-classes` / `no-unknown-classes`). https://npmjs.com/eslint-plugin-better-tailwindcss
- Playwright `toHaveScreenshot()` baselines, tolerances, masking volatile images, OS-specific baselines. https://playwright.dev/docs/test-snapshots

### Accessibility baselines

- 3:1 non-text contrast incl. focus indicators (SC 1.4.11). https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html
- Stock button focus ring is `ring-ring/50` (50% alpha) — a teal/sage ring at 50% on cream may fall below 3:1. Stock sizes: h-9 default, h-8 sm. https://raw.githubusercontent.com/shadcn-ui/ui/main/apps/v4/registry/new-york-v4/ui/button.tsx
- Target size ≥24px (SC 2.5.8); aim 44px on touch surfaces. https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
- Text 4.5:1 (SC 1.4.3): check primary-foreground on accent fills and accent-as-text on cream in both modes; may need separate text/fill accent tones.
