## Web research findings
- [web] Backloggd: no storefront import (gap). twoaveragegamers.com/backloggd-review
- [web] Grouvee: background/nightly Steam import, "Steam" shelf, opt-in email, unmatched → "import help" page for manual linking; re-import by re-adding URL. discuss.grouvee.com/t/steam-games-not-importing/2374
- [web] WListDB: pull whole library, user picks which to add; already-tracked games shown separately; playtime re-sync. wlistdb.com/steam-library-import
- [web] Loudplay: integration card with status Success/Pending/Error, last sync time, "Rate Limit" state ("wait about an hour"); manual sync ~once/day recommended. chat.loudplay.io/hc/help/articles/linking-your-steam-account
- [web] Playnite: "Update Game Library" + automatic metadata download; completion notification with counts; never auto-removes games gone from source; incomplete metadata if interrupted. api.playnite.link/docs/manual/library/games/faq.html
- [web] Backloggery interop: "added / removed" counts; unlinked list per source. greasyfork.org/en/scripts/386681-backloggery-interop
- [web] Letterboxd: exact vs best-guess match; review before commit; re-import merges. letterboxd.com/about/importing-data/
- [web] LibraryThing: progress visible from anywhere, can stop, "Your Imports" history, notified on finish/needs input. blog.librarything.com/category/import
- [web] StoryGraph: import up to ~24h; wrong-edition matches. Bookshelfed: nothing skipped, unmatched kept with raw data, re-imports allowed.
- [web] Conventions: say "you can leave this page"; show X of Y; small state set (queued/running/done/failed); notify on completion with CTA; visible running job prevents double starts; unmatched → dedicated "needs linking" list; re-sync adds new only, never auto-removes; Steam silently hides some F2P titles.
- [web] Pitfalls: Steam needs "Game details" = Public (default Friends only) AND "Always keep my total playtime private" unchecked; private library returns empty response (indistinguishable from empty library; intermittent empty responses on public profiles too); Steam takes ~5–7 min to apply privacy change; new purchases 5–10 min to appear; stuck/partial imports with no errors (Grouvee, LaunchBox, Backloggery 600→100); premature "complete" notifications (LibraryThing); wrong matches from fuzzy titles. developer.valvesoftware.com/wiki/Steam_Web_API; help.digiphile.co/steam-account-linking
- [web] Terms: import = one-shot copy; sync = repeatable refresh with last-sync time/status, removals not propagated; matching = resolve to canonical record (exact via external id, best-guess via title).
