## Codebase findings

### Data model
- Statuses: enum `LibraryItemStatus` WANT/PLAYING/DONE (`prisma/schema.prisma:248-252`). Labels are in `src/entities/library-item/model/status.ts:26-35`. `NEXT_STEP`: Want→"Start playing", Playing→"Mark done", Done→"Play again" (`status.ts:59-66`).
- Up Next
  - `LibraryItem.upNextPosition Int?`, unique per user (`schema.prisma:126,135`). `UP_NEXT_MAX = 5` (`status.ts:68`).
  - Queue marker: "Up Next #n" for Want, "Replay" for Done (`status.ts:70-81`).
  - Starting a game takes it out of the queue and compacts the queue (`src/entities/library-item/api/set-library-item-status.server.ts:98-105`).
- Done outcome
  - `DoneOutcome` FINISHED/LET_GO on `LibraryItem.doneOutcome` (`schema.prisma:128,254-257`). Labels: "Done · Finished" / "Done · Let go" (`status.ts:83-90`).
  - Private, never aggregated (`src/features/done-follow-up/CLAUDE.md:13-23`).
  - Never cleared when leaving Done (`set-library-item-status.server.ts:126-129`).
- Notes and sessions
  - `JournalEntry` fields: `playedMinutes`, `prompt` (WHY/STAYED), `gameId`, `libraryItemId`, `playthroughId`, `createdAt` (`schema.prisma:158-188`).
  - A session is a note with `playedMinutes > 0`. Time played is the sum of those minutes (`src/entities/game/api/get-game-details.server.ts:117-121`).
- Plays: `Playthrough` (`schema.prisma:190-209`).
  - Becoming Playing opens a play; leaving Playing closes it.
  - Logging time adds minutes to the open play (`src/entities/journal-entry/api/create-journal-entry.server.ts:60-74`).
- Rating: `LibraryItem.rating`, 1–10 half-stars (`schema.prisma:124,146`).
- Times to beat
  - Fetched live from IGDB `/game_time_to_beats` (`src/entities/game/api/get-times-to-beat.server.ts:21-60`). Only `normally`→`mainStory` and `completely`→`completionist` are read, in seconds (`:56-57`). Nothing is persisted; there is a 10-minute response cache (`src/shared/api/igdb/response-cache.ts:65`).
  - The `Game.mainStory/mainExtra/completionist/hltbId` columns exist (`schema.prisma:89,94-96`), but nothing in src reads or writes them. There is no HLTB client.
  - **Unverified label issue:** in IGDB, `hastily` is the time to the credits and `normally` includes some extras. If so, today's "Main story" label shows main + extras. api-docs.igdb.com returned 403 to WebFetch, so this was not confirmed.
- Critic score: IGDB `aggregated_rating` 0–100, read live (`src/widgets/game-detail/ui/game-detail/game-detail.tsx:68`). Drawn as `CriticScoreRing`, hidden when there is no score (`src/entities/game/ui/critic-score-ring/critic-score-ring.tsx:14-45`). Its aria-label lacks the number.
- Platforms
  - Game page: IGDB `platforms[].name` shown as `PlatformBadges` in the Themes card (`src/widgets/game-detail/ui/themes-tags-panel/themes-tags-panel.tsx:52-58`).
  - Per library item: a single `LibraryItem.platform` string.
- Cover
  - `Game.coverImage` is a full IGDB `t_cover_big` URL (`src/entities/game/api/upsert-game.server.ts:31`). Sizes come from `src/shared/lib/igdb-image.ts`.
  - `GameCover` (`src/shared/ui/game-cover/game-cover.tsx`) has no `crossOrigin` attribute.
- Status chip: `src/shared/ui/status-chip.tsx` (want/playing/done/let-go). Mapping in `src/entities/library-item/model/status-chip.ts`. Wrapped by `StatusControl` with `StatusPicker`.
- No color-extraction code, no image library, no CSP.

### Corrected inference
- The codebase agent assumed canvas sampling of IGDB covers would hit CORS. That was checked in-session on 2026-11-10: `curl -sI -H "Origin: https://continueapp.vercel.app" https://images.igdb.com/igdb/image/upload/t_cover_big/co1r7f.jpg` returns `access-control-allow-origin: *`. Client-side sampling works if the image loads with `crossOrigin="anonymous"`, which `GameCover` does not set today. Precomputing on the server and storing the color is the alternative.

## Web research findings

- Continue rows are chosen by recency, not by the user. Examples: Xbox "Jump back in" (https://gamesradar.com/xbox-is-finally-getting-a-better-home-screen-heres-your-first-look) and the Steam 2019 library, which shows recently played games with last session and playtime (https://pcgamer.com/new-steam-design-2019).
- Netflix "Remove From Row" only hides the title; progress is kept and there is an Undo (https://help.netflix.com/en/node/115312). Apple TV "Up Next" dismissal is hard to find, and users complain (https://discussions.apple.com/thread/255807260). Make dismissal a primary, equal-weight action.
- The choice-overload evidence is weak. The Scheibehenne 2010 meta-analysis found a mean effect near zero (https://abcwest.cogs.indiana.edu/pmwiki/pdf/scheibehenne.options.2010.pdf). Justify the one-question Home by calm and intent. Keep a visible route to the full overview (Hick's law caveat, https://lawsofux.com/hicks-law/).
- Deferred prompts often cap repeats; Oracle Guided Learning stops after 3 (https://docs.oracle.com/en/education/customer-success/guided-learning/ogl-faq/how-setup-remind-me-later-button.html). The owner chose "nothing remembered".
- Dominant color
  - Material Color Utilities `Score` drops low-chroma colors and falls back to Google Blue when nothing survives (https://raw.githubusercontent.com/material-foundation/material-color-utilities/main/typescript/score/score.ts). A neutral fallback must be defined.
  - Android Palette and node-vibrant swatches can be null, so a default is needed (https://developer.android.com/develop/ui/views/graphics/palette-colors).
  - Artwork colors often fail contrast (Spotify, Symfonium). The fix is a per-theme, contrast-safe variant (https://support.symfonium.app/t/automatic-now-playing-section-colors-often-lack-contrast/5458).
  - OKLCH recipe: keep hue and chroma, clamp lightness per theme (https://evilmartians.com/chronicles/better-dynamic-themes-in-tailwind-with-oklch-color-magic).
  - YouTube Ambient Mode is a soft gradient wash (https://9to5google.com/2023/10/27/youtube-ambient-mode-off/).
  - Unsplash ships a precomputed dominant `color` per photo (https://unsplash.com/documentation/changelog), a precedent for precompute-and-store.
  - Canvas `getImageData` needs `crossOrigin="anonymous"` plus host CORS (https://corsfix.com/blog/tainted-canvas).
- Evenings
  - No product expresses length in evenings, so this is new.
  - Medium "N min read" rounds (https://help.medium.com/hc/en-us/articles/214991667).
  - Kindle separates the typical time from your own pace.
  - StoryGraph users asked to set their own estimates (https://roadmap.thestorygraph.com/requests-ideas/posts/tbr-reading-time-calculation).
  - HowLongToBeat data is user-submitted. About half of games have a main-story time, and samples can be small (https://www.twoaveragegamers.com/howlongtobeat-review-still-the-best-free-answer-to-how-long-is-this-game/). An empty state is needed.
  - Round figures avoid false precision (https://shape-of-code.com/tag/actual-time).
- Game page
  - Critic scores appear as small badges, often opt-in (Steam: publisher choice; Epic: OpenCritic % recommend) (https://www.pcgamer.com/epic-games-store-now-has-opencritic-reviews). This supports a small score.
  - Steam game page: banner, then a "your last session" block (https://pcgamer.com/new-steam-design-2019).
  - Letterboxd: poster with an action cluster beside the facts. Its backdrop is missing for less-known films, so a fallback is needed (https://androidauthority.com/what-is-letterboxd-3216354).
- Not found
  - No research on Headspace or Duolingo single-CTA screens.
  - Infinite Backlog and Grouvee have no comparable Up Next.
